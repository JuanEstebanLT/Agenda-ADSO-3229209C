# Mini-Sitio v3

Proyecto académico correspondiente a la Semana 3 del Proyecto Integrador (Control de Versiones).

## Descripción

Este Mini-Sitio es una aplicación web básica desarrollada con HTML, CSS y JavaScript.  
El objetivo es aplicar buenas prácticas de gestión de proyectos usando:

- Issues accionables
- Tablero Kanban (GitHub Projects)
- Pull Requests
- Trazabilidad con `closes #id`

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git y GitHub
